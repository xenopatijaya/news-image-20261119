# Thursday 19 November 2026 — 40+ stories, six continents, one front page

An entry for the [make.fun](https://make.fun/bounty/news-image-20261119)
bounty **news-image-20261119**: "Sum up 19 November's world news in one image".

The image is a newspaper front page for Thursday 19 November 2026: the
Xi–Trump–Putin trilateral in Shenzhen and the worldwide GTA VI rollout as
the two leads, a world map with eight flashpoints, and a grid of 40 short
labelled stories across Europe, the Middle East, Asia-Pacific, the
Americas, Africa and Oceania — 42 stories in total, all reported on
19 November 2026.

`main.py` (Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR` (default `/output`). `draw_frontpage.py` draws the
front page from scratch with PIL; run it to regenerate `entry.png`.
